# data/

Numeric extracts from the public documents behind the article, with provenance in `README.md` and SHA-256 checksums of every source file in `source_checksums.txt`.

| File | Contents |
|---|---|
| `annex14_table5.csv` | 112 built and consented farms, worst-case scenario (Annex 14, Table 5) |
| `annex14_table6.csv` | The same farms, known-case scenario (Annex 14, Table 6) |
| `latt_coefficients_table7.csv` | Coefficients of the six approved turbine models (Annex 14 Table 7 = Annex 5 Table 2) |
| `annex13_table3_measured_vs_2014.csv` | Measured impact vs the 2014 model, and which campaign fitted each 2026 model |
| `osm_turbines_50km.csv` | Turbine positions within 50 km of the array (OpenStreetMap, ODbL) |

The source documents themselves are not redistributed. Nothing in this folder is edited by the analysis scripts.
