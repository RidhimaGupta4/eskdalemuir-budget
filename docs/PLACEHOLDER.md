# docs/

The built interactive dashboard, `index.html`, served by GitHub Pages (Settings > Pages > Deploy from a branch > main, folder `/docs`). It is generated by `scripts/07_build_dashboard.py`; do not edit it by hand.

The page runs the 2026 algorithm in the browser and checks it against 30 reference values from the Python code every time it loads. `.nojekyll` tells GitHub Pages to serve the folder as plain files.
